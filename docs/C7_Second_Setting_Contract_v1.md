# C7 second-setting content contract

This engineering extension implements timed maintenance/handover runbooks on `WorkflowEngine`, a subclass of the existing C6 engine. The old request classes, recipe definitions and `SelectionEngine` remain supported. `WorkflowRequest` uses the same object store, Fool's Memory bindings, explicit Model A work, actor wallets, reservations and native material laws. Workflow checkpoints have a new schema. Importing an old checkpoint as that new schema is not supported; the existing C6 restoration API remains available.

A task is `(id, primitive, predecessors, earliest_slot, latest_slot, responsible_actor)`. There are at most eight distinct tasks, eight source inputs, two participants and 1,001 possible local slots. Each task occupies one serial equipment slot. Windows are hypothetical procedure constraints, not elapsed simulator time or proof of performance. Known primitives are inspection, care, use, transfer and return. No new physical law is introduced.

Reconciliation intersects windows for equal task identities, retains conflicting primitive/dependency/assignee variants as explicit conflict, preserves inherited unresolved conflicts through nesting and teaching, retains missing dependencies, detects blocked cycles and reports missed windows. It chooses the earliest feasible ready task, with lexical tie breaking. A later query supplies a hypothetical set of completed tasks and a local time and selects an eligible task by deadline and identity. A query cannot skip prerequisites in actual physical work. This is a bounded scheduling policy, not an optimal scheduler or a derivation from the source papers.

Concrete events carry their actual occurrence tick when delivered, and activity inference orders them using that paid-read field. Observed order remains a scoped hypothesis, not proof of universal necessity. Readiness and Embody responses depend on delivered condition, wear and custody: a worn serviceable tool calls for care before use, a maintained tool permits a use prediction, and a damaged tool calls for inspection without granting repair competence. Repeated delivery of one event cannot count as two distinct activities. A sent model, correct answer and assent remain different facts. Teaching never calls the native acquisition operation or confers practiced skill.

The Act second setting concerns custody restoration and ownership handover, which changes who can use equipment and discharges an actual relation. Its original setting concerned repair/use and condition. For the other self-routes, task order, temporal windows and assigned responsibility add constraints absent from the original personal condition/scalar shared-cap/static interface examples. Crossing routes now use these task structures and actual maintenance histories instead of scalar caps. This is more than changed names, quantities or types.

Every body of shared content requires a real scoped group. Offers include an actor-owned stance; receiver replies require delivery and paid reading and compute an answer to the offered question. Main social routes consume the exact source/offer/reply triple. A disagreement can be understood without being accepted. A draft is not an authorized rule. Mobilize and rule-governed physical actions consume a one-attempt allowance; cancellation does not restore it. Native custody, stock and exact material revision checks still govern actual work.

Composite Fold steps retain an intermediate result; the later step consumes that exact result. Defining-step controls replace the resolved content with an empty, nonauthorizing result, or withhold the material command, without changing the main movement's costs. They are deliberate experimental violations and must fail the ordinary semantic auditor. Downstream work is separately charged and can differ because it consumes different content. The auditor independently reconstructs input access, schedules, output fields, authority, steps and prices; the inherited independent auditor checks physical effects and wallets.

This task targets the second-setting gate. Native setting witnesses are scripted coverage cases. Automatic selection, Shell application and population scheduling remain inherited evidence for the original content language; the new workflow domain is not silently credited with those integrated release gates. General nesting, unrestricted meanings, optimal scheduling and unbounded development remain outside this contract.
