## What U14 delivers

The 51 native modules and 98 legacy modules remain byte-identical to U13. U14 adds a frozen behavioral panel, longer mixed-type group evaluations, independent per-owner resource reconstruction, exact interrupted continuation, stricter negative controls, a fail-closed assessment tool and a self-contained read-only inspector. The source includes all inherited code, the exact U12 reference, specifications, protocols, tests and reproducible commands.

The inspector separates processed participant accounts from explicitly selected evaluator history. It supports gzip checkpoints, owned jobs, learned capacity, pending deliveries, raw accounting and exact historical object revisions. The supplied HTML export shows Bob after the first abundant population case, including succession and retained public history.

## Preserved failures and execution limits

Development evidence includes missed observation steps in the first harness, an invalid empty-panel configuration, a three-use case with insufficient care supplies, and two stages of inspector serialization repair. Nine final U14 tests and a complete sustained-checkpoint HTML export validate the corrected exporter; the exported client script passes syntax validation. A browser-render inspection was unavailable in this runtime.

The first release attempt was interrupted for the exporter-only amendment. Its source manifests, partial episodes and source-change guard rejections during shutdown remain under `interrupted_exporter_v1`. Participant runtime, original cases and thresholds were unchanged, and final panels were reexecuted.

An initial monolithic legacy run stopped producing progress at a test that passed in isolation. That attempt was interrupted and retained. A second monolithic run with periodic diagnostic stack snapshots progressed further, then terminated with an interpreter segmentation fault after 716 completed tests. Both attempts remain in `legacy_stalled_attempt/` and `legacy_crashed_attempt/`; their root causes are unresolved. The final regression result runs all 840 unchanged tests in 37 fresh module processes under the prospectively frozen `U14_Regression_Execution_Amendment_v1.json`, with no omitted tests, assertion changes or automatic retries. Every module exits normally. This establishes the complete regression population in the declared process-isolated mode, not successful completion in one long-lived interpreter. The earlier failures remain a material execution limitation.

All original care-scarcity gate failures remain visible. The delivered evidence also contains the unchanged U13 package with its earlier failed optimization candidates. No failed or resource-limited episode is silently reclassified as completed useful work.
