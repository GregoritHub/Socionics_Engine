# U12 Development record

21 September 2026

The U12 protocol and its digest were written before the first U12 execution. Its detailed criteria refine the original three U12 cases as documented in the architecture. The protocol was not weakened after testing.

Development logs and partial witnesses are retained in the evidence package. They include:

- The first setup attempted to declare material after engine initialization. The inherited resource authority correctly rejected this. The fixture now declares its unspent resources in the initial world and then performs acquisition normally.
- An institution was initially labeled as a collective without the required Composition facet. The common object validator rejected it. Institutions now use governance records referencing the existing group, preserving the membership distinction.
- Simultaneous independent old blame and new neutral fact records created contradictory current evidence. The fixture now versions one environmental observation source, while preserving the original episodes and generated pattern.
- Counterproposal and dispute witnesses initially omitted required paid reads. They were corrected to disclose and process those actual records. The runtime access checks were retained.
- The first 39-test development panel produced four errors: a missing Governance test import, two reused command identities in boundary subcases, and a missing address test import. No runtime assertion failed in that panel. All affected tests were rerun after correction.
- Review added revocable proposal consent and traceable dispute resolution. It also strengthened the independent audit so its U11 extension cannot accept a changed coordinator without a matching enacted institution.
- Succession and dissolution now preserve the existing material prototype without requiring a newly generated procedure. The corresponding test protects administrative participation when new material planning is unnecessary.
- The second material witness now starts with a damaged pump and a lower wear limit. Its initial procedure includes an actual repair before use and care; it is not merely a renamed copy of the tool fixture. Both still use the same material laws.

The final evaluation uses one frozen execution manifest. Development results are not substituted for that reproduction. The final evidence records every test row, raw witness check, failure, partial episode, audit and source identity. No U14 or legacy release seeds were used.
