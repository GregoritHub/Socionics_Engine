```sh
python tools/reproduce_u8.py --out /tmp/hle-u8-reproduction
python tools/inspect_u8.py /tmp/hle-u8-reproduction/u8_witnesses/development_and_returns.checkpoint.json --actor alice --assess
```

Python 3.12 and the standard library are sufficient. `--assess` prints a separate offline evaluator view; it does not change participant decisions.
