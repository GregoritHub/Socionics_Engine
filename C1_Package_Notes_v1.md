# C1 package notes

This source archive is self-contained and retains the entire supplied U14 source tree, including its frozen historical baseline and evidence fixtures. The archive is consequently much larger than the four new C1 modules. No historical baseline members were removed to produce an apparent engine storage gain.

The original native source differs only in the two optional offline audit interfaces, `cognitive_audit.py` and `operation_audit.py`. New C1 modules, tests, tools, protocols, reports and the current README are separately identified. The C1 execution manifest covers current executable modules and contracts. Old U14 manifests retain their historical meaning and are not rewritten to bless the new release.
