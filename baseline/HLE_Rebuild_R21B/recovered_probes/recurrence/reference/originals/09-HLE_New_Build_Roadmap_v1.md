## Rules that apply throughout

1. **Source fidelity:** New rules declare their source and status. Reuse an old test only if its encoded assumptions remain accepted.
2. **Causal integration:** Each stage extends the same event-to-memory-to-action process. Separate modules are useful only when they participate through explicit interfaces.
3. **Grounding:** Truth is an evaluator reference. Participant actions use their own permitted information and resource state.
4. **Assessment:** Correctness, identity preservation, path quality, and retained capacity are separate outcomes. Missing evidence remains unassessed.
5. **Efficiency:** Use changed-state work and compact references from the start. Measure cost after integration; checkpoint and performance checks are recurring gates, not work postponed entirely to R10.
6. **Open-ended development:** Broader expression and composition are goals. Every measured result names its actual limits; a finite test cannot establish unrestricted development.
7. **Progress reporting:** After every milestone, report completed work, evidence, failures, remaining count, and next step. If a milestone must split, publish the numbered replacement substeps before treating the parent as complete.
