## What changed

Crux movements now perform operations over relational Fool's Memory and consequential actions. Theorize derives an account from exact recalled proposition indexes, with explicit ambiguity and provenance. Apply selects and executes inspection/transfer through the world. Embody retains observed consequences and can acquire an object-independent checking procedure when experience contradicts the prediction. The alternate Understand movement retains a tentative personal interpretation without forcing physical application.

Model A now participates in execution. The current IE moves through transported-cube paths via an eligible polarity support seat; resource limits retain partial progress. The structural adjacency, fields and support-seat correspondence retain their original source grades. Operator-to-IE targets, forced support visits, numerical prices and deterministic path selection are explicitly experimental policies. They are not derived psychological laws.

The new layer extends the R3 world and shares its single journal, wallets, observations and exact memory references. Processing state, accounts, applications, acquired procedures and work histories survive replay. Physical inspection and subsequent transfer are separate paid transactions. A failed action, partial action, zero-resource deferral or stale retention attempt remains visible.

## Worked circuit

The 23-transaction demonstration begins with Bob retaining the public observation that Alice owns the box. Alice transfers it to Bob without informing him. Bob recalls his exact old memory and Theorize derives the account that Alice owns it. Apply inspects, observes Bob as owner, then executes the requested transfer back to Alice. The discrepancy is retained even though the final owner equals the initial prediction.

Embody produces memory revision 2 and acquires a generic inspect-before-transfer procedure. The old cue still points to revision 1; an explicit new cue names the lesson. On a different object, the recalled procedure causes inspection before transfer. A subsequent Theorize → Understand branch retains a personal account and returns to I without a physical application. Bob spends 159 energy and 159 time quanta across all memory, processing and action work in this fixture.

The harness supplies goals and demand order. The implemented operators derive accounts, discrepancies, action choices and retained outputs. The acquired procedure comes from a supplied grammar; this is not unrestricted procedure invention or an autonomous population demonstration.

## Bounded cost result

A first profile found repeated reconstruction of fixed Model A geometry: about 38.2–38.9 ms per Theorize/Understand pair plus selective input. A bounded cache now reuses only immutable geometry, keyed by type frame, start, target, polarity and price mode. It contains no memory, actor, conclusion or paid progress.

The complete demo checkpoint, transaction trace, routing records, type controls, capacity controls and hash-seed results are byte-identical before and after this change. On the same workload, median time falls to about 0.58–0.62 ms. This is a roughly 63-fold improvement for this repeated, largely warm-geometry workload, not an engine-wide or cold-start speed claim. The initial profile and source snapshot remain in the evidence archive.

## Remaining boundaries

R4 implements four movement/face pairs over a supplied ownership/checking grammar, not all 32 realized transformations. It does not establish conductivity, IDEA return, Shell generation or clearance. The exact prices, operator IE assignments and routing selector remain hypotheses. The Id/Identity recurrence, deeper card-to-Crux correspondence, recursive composition and empirical calibration remain open.

The R2 and R3 loaders remain available, but automatic session migration is not included. One unfinished Crux movement per actor blocks starting another until resumed; no cancellation operator is included. Participant isolation remains an API boundary for cooperative code. Goal scheduling and cue selection are not yet independently adapting policies.

The source package is self-contained, with original papers, source code, tests, reproduction tools and the complete updated step list. The separately attached roadmap failed to load; the preserved roadmap inside R3 was used instead. The former 12A track remains separately paused at parent progress 4/14, with 11 former actionable steps remaining and efficiency acceptance open.
