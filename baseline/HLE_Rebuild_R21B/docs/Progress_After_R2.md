## R3 starting point

Build relational Fool’s Memory on the current `hle` package. Reuse exact world/observation/memory references and the R2 retained-revision boundary; do not create an independent duplicate event store. Keep card identity, fold location, context, associated content, historical binding and cursor competence separate.

State the retrieval/revision policy as an implementation choice before evaluating it. Demonstrate context-sensitive cue reuse, multiple cues per memory, useful variable recall structures, faithful historical bindings and navigation competence independent of stored organization. Id/Identity traversal remains unelected unless a new rule is explicitly justified.

Connect the memory policy to the permitted observation and action interfaces. Preserve actual work charges, incomplete work and unknown factual status. Use actor-specific inbox cursors and changed-event indexes; add selective memory access without scanning inactive global history. Extend replay and continuation checks to the new memory indexes and any persistent controller state.
