# Recursive composition proposal in R7

Declared before implementation acceptance. This is an implementation hypothesis,
not a proof of recursive Cross coherence. Foundation §3/R7 requires recoverable
lower organization; the Fool's Memory manual P0084 separates folding from
unfolding. Neither supplies the executable law below. Canon §6 Eq.17 remains a
separate obligation; finite successful executions do not establish closure.

## Chosen law

A composition is an owned immutable revision containing an ordered tuple of
`(role, exact child revision, access context)` parts. A child is an owned memory
revision or an already retained composition. All references point backward in
the journal: the revision graph is a finite DAG, including when a later revision
uses an earlier revision of the same named organization. No fixed depth, tier
ladder, geometric rank, developmental successor or card correspondence is added.
Different roles may share one child. Unique role/context pairs distinguish
occurrences. Edges and ordering remain part of identity, not just flattened text.

Fold stores direct constituent addresses, an exact predecessor and the elected
law reference. It never stores a pointer to mutable current owner state.
Unfold visits exact nodes iteratively, retains every selected edge and returns
each unique node and capability once. A full structural unfold has no context
filter and cannot be passed to the ownership operator. Contextual access follows
only edges bearing the requested context, filters propositions by their original
context and explicit query time, and preserves exact proposition/owner/role
identities. No context or actor is silently renamed. Direct record inspection is
diagnostic, like inherited memory inspection; participant use requires a paid,
completed access result. Lower memory links/provenance remain exact addresses,
not additional automatically traversed composition edges.

One fold unit plus one per direct part is charged. Unfold charges one per node,
one per selected outgoing edge for a composite, and one per stored proposition
and capability reference for a leaf. One unit consumes one energy and one time
quantum. These are supplied engineering prices. An unfinished node retains paid
progress; no result is exposed until completion. A resumed fold keeps its
original specification and fails, without refund, if its expected head changed.
Historical access remains allowed after a newer child revision exists.

Contextual access connects to inherited R4 Theorize through an owned completed
result containing exact memory hits and capability references. R4 still pays
its routing/content costs and selects/executes its own action. Apply and Embody
retain consequences normally. The existing R6 scheduler and local policy remain
available; composing and choosing a composition are supplied operations in R7,
not participant-generated institutions (R9).

## Declared assessment

A test declares a root revision, context, expected child-supported ownership
claims, required capability rule names and maximum per-use path cost before the
tested use. Evaluation separates: exact contextual unfold identity; child
agreement with declared claims; freshness of pinned child revisions; factual
agreement with Truth at the stated evaluation moment; cost of access + Theorize
+ Apply + Embody; and actual successful transfer with retained required capacity.
An equal-time conflict fails agreement. Missing evidence remains unassessed.
Expected values and budgets cannot change inside a test. A replacement definition
or test is a new record; old failures stay addressable. All uses after declaration
remain in its family, so a later success cannot erase a failed use or costly path.

Child revision changes invalidate contextual ancestors through reverse edges;
world fact changes invalidate factual checks through exact fact keys. Upcoming
claim start/end boundaries are indexed. No invalidation scans the journal or
unrelated tests. Reassessment may inspect the affected view's reachable graph
and its use family. This is not constant cost in composition size or related
history. An independent offline oracle reconstructs references, current heads,
facts, accesses and uses from the journal for comparison.

Historical organization can unfold identically while a current parent claim is
stale, false or unsupported. Refreshing a leaf does not rewrite its parents:
explicit parent revisions are required to adopt it. General finite-composition
closure, autonomous higher-order discovery, broad language, new kinds of learned
operators, cross-owner private-memory access and sustained population efficiency
remain unestablished.
