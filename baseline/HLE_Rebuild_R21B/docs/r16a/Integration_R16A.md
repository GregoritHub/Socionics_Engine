R15 preserves a paid, generated external-prerequisite pattern, but its journal does not independently record all five Shell-sign mechanisms. The frozen R12 declaration requires runtime evidence for R16.1–R16.3, separately from its five detector-fixture gates. Calling the same confirmation pattern five signs would change those criteria.

R16A therefore supplies and verifies the complete assessment boundary and one supported live channel. R16B must supply the missing runtime mechanisms and controls. This split was declared before the new evaluation. R16 is not marked complete, the R12 declaration is unchanged, and parent progress remains 4/10.

## OIG projection

Each engagement has a fixed actor, TIM, material lineage, context, protocol, projection version and exact occasion. Claims align on subject, relation, context and occasion before comparison. The twelve lenses then use their recovered equality definitions.

Runtime domains represent actual effects: internal comparison/revision uses I; paid request/response exchange includes WE; inspection and physical return include IT. The adapter does not invent an ITS organization from a route label. A stable material-lineage reference is projected as foreign content when the operation uses scoped conceptual content that conflicts with the actor's own unambiguous interpreted loan terms. This is a declared finite projection, not a universal definition of foreign material.

V is observed change; N is endpoint difference; K is V minus N. R stores equality-class positions rather than all recurrence pairs. Nonzero K, identical states or native-route persistence cannot classify a sign. The same OIG trajectory yields rest or foreclosure in the matched fixture solely because the independent demand/opportunity evidence differs.

`OIGAccumulator` maintains twelve equality indexes. An independent bounded comparison uses `observe_trajectory`. All twelve results, including exact recurrence partitions, agree in the tested fixtures and live trajectories.

## Live integration

`ShellAssessmentWorld` is a `CompensationWorld` with a derived transaction observer. It introduces no new participant commands, policies, resource penalties, conceptual facts, or stored verdicts. The base R15 checkpoint remains valid; restoring through the new subclass reconstructs the observer by replay. The original class still restores identical bytes.

The monitor resolves actual owned observations, generated return demands, conceptual revisions, R15 material origins, paid consideration, externalization, delivered responses and paid assimilation. Eligibility requires accurate usable terms, an active accepted return demand, clean due ownership, practiced care/release, and adequate resources for the declared revision alternative. The quote reuses the structural tariff without invoking participant choice. Physical ownership remains separate from conceptual material lineage.

A correct completed return closes an engagement. The monitor counts a loan once even if two carriers were tried. Incomplete jobs and open engagements remain unassessed. Quiet ticks do not create engagements. Historical positive evidence is retained when later behavior changes; the report does not certify current persistence, clearance or recurrence reopening under R19.

R15 supports a strong forced-placement witness: the current terms permit release, but the actor externalizes its unnecessary conceptual prerequisite and retains it after processing the peer response. It does not independently expose a required but skipped distinction, a new defense born after a comparable demand increase, inconsistent post-integration fragments, or a necessary noncurrent movement prevented by an observed mechanism. Those four runtime channels remain unassessed.

## Replay, cost and scope

`shell_reference.py` independently folds raw transactions, identifying placement, eligibility, endpoint success, actual work and quotient representatives. It does not call the live monitor, detector predicates, projection function, participant selector, or runtime material indexes. It shares only the structural tariff and recovered mathematical OIG reference.

Ordinary ingestion updates affected transaction records and indexes. Closing a loan evaluates that loan's operations, not all previous loans. Physical endpoint lookup uses four addressed facts. Reports and independent audits are explicit offline traversals. Histories, stored evidence, checkpoints and relevant active work still grow; this is not R21 efficiency acceptance.

The fixture panel is boundary testing, not a second simulated society. R16B must extend the existing causal process with genuinely consequential witnesses and matched ordinary controls, then connect the remaining channels to this assessor. R17–R21 remain unchanged and open.

Opportunity timing is explicit: the owned evidence must be delivered and interpreted no later than `engaged_at`. Later interpretation cannot retroactively establish usability or turn missing eligible evidence into a negative finding.
