Their comparison is a partial order: greater demand requires explicit increased requirements within the same scope. Changed context or resources cannot silently become a greater-demand claim.

Capacity records retain acquisition, contextual bindings and dependency revisions. Phase and closure claims require evidence; a censored search or an added wrapper cannot establish coherent closure. These are executable contract checks. Live reference resolution and behavioral assessment remain later integration gates.
