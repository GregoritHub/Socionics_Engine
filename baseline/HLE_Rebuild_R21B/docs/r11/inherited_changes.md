# R11 changes to inherited acceptance expectations

The original R10 archive and its results remain historical evidence. None is renamed as an R11 result. The full R10 source archive is preserved in this release's reference/originals directory. All original governing reference files are byte-identical.

| Inherited check | R11 adjustment | Preserved distinction |
|---|---|---|
| Language `test_competing_learning_revision_fails_paid_job` | Renamed to `test_competing_learning_requires_cancel_before_revision`. A second semantic job now rejects while the first owns processing. Cancel the first, then execute the competing revision. | Prior cost remains paid; the cancelled job publishes no lexeme; the newly authorized revision is retained. Separate new tests change owned R3 evidence during partial work and require failure without publication. |
| Organization `test_changed_state_fails_partially_paid_plan` | Renamed to `test_leave_requires_cancel_before_changing_local_state`. Leaving cannot interrupt another semantic operation without first cancelling it. | No partial plan becomes executable; cancellation preserves payment, permits a subsequent paid withdrawal and releases processing. A separate new test revises owned evidence during partial Perform and requires terminal failure. |
| Composition `test_inherited_runtime_tests_and_references_unchanged` | Adds processing.py, metabolism.py and socion.py to the explicit edited-runtime set. | R4/R6 funded-hop advancement is factored into one shared pure helper. The original positional oracle, all R4/R6 semantic tests, and original hash register remain unchanged; R11 adds full shared-state checks. |

The other 337 inherited test methods retain their original assertions. R11 preserves declared TIM, Ne default initialization and emission from actual active state. Sufficiently funded semantic/physical results retain the original meaning checks and evidence restrictions.

R11 language and organization checkpoint schemas are `hle-r11-language-v1` and `hle-r11-organization-v1`. Jobs add immutable route specifications and transactions add explicit processing states; a fixed semantic-routing ablation policy is checkpointed. Earlier R8/R9/R10 live checkpoints must be replayed with the preserved old release. This milestone deliberately provides no silent migration. R2-R7 checkpoint contracts remain unchanged.

R8/R9 semantic prices intentionally change: the original content extent is multiplied by the selected target seat's price and paid route hops are added. The new independent oracle checks those prices; an old R10 numerical price is not treated as an R11 expectation. R10's archived performance declarations and evidence are unchanged.
