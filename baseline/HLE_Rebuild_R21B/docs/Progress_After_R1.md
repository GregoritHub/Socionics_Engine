## R2 starting point

Use the new `hle` package as the code root. Begin with two actors and a small ownership-transfer world. Implement versioned referent resolution, deterministic event ordering, truthful world changes, limited observations, explicit messages and real resource transactions over the R1 contracts.

The required controls include changing a hidden fact without changing the participant's input; a belief that exists but is inaccurate; a failed action after spending resources; incomplete work that remains incomplete; explicit correction of an event; and deterministic replay/continuation. These are new runtime tests, not consequences of the R1 schema checks.

Keep Truth and evaluator interfaces out of participant decisions. Use event/revision changes to schedule affected work. Preserve information and costs needed for subsequent comparisons rather than rescanning all inactive history each tick.

## Boundaries retained from preparation

The initial A01–A15 panel remains planned through R5. R1 provides supporting types and structural checks, but does not close cue-retrieval, observation-isolation, generated-Shell, clearance, checkpoint or incremental-runtime gates.

The Id/Identity cycle, full navigation policy, card-to-Crux correspondence, recursive coherence, sign-specific Shell detectors and numerical processing costs remain explicitly open or unelected. The club-to-perspective correspondence remains a source postulate. No color ladder or automatic drain rate has been added.
