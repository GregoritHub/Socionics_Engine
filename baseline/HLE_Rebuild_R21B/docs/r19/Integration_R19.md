## Clearance proof and current validity

The read-only observer requires three eligible positive maintenance engagements for each of the five target signs before it can certify their clearance. It then requires the original return and every one of the twelve declared challenges. A quiet interval or a single successful endpoint cannot pass.

A positive case needs current material access, the same retained capacity revisions, independent own work, actual accepted shared output, an evidence-grounded conditional return and two potential carriers. No persistent target mechanism may recur. The finite positive proof conservatively requires the old defensive account work and optional confirmation work to be absent. This does not classify all future account processing as defensive; it limits what this particular clearance proof certifies.

The observer records the exact supporting revisions and historical witnesses. It checks both direct references and their originating events. Material suppression, capacity withdrawal, evidence withdrawal and native prospective world corrections invalidate affected current claims. Removing an unrelated clock event has no effect. Restoration of access does not automatically turn earlier success counts into a new clearance. A new full clearance window is not implemented in this release; the delivered lifecycle evaluates one frozen window and its subsequent validity/recurrence.

An unsuccessful consequential return or renewed work failure reopens the claim immediately as unresolved. Repeated positive target mechanisms make it recurrent at three distinct eligible engagements, with two/five sensitivity recorded separately. A later correct endpoint does not erase the intervening path. Historical positive Shell findings and the earlier qualified clearance remain in the assessment history.

The recurrence intervention deliberately exercises the still-addressable old account through paid source substitution, actual messages, post-challenge structure, blocking and carrier confirmation. It does not assign a sign flag. The displacement control closes the first carrier's boundary, processes its refusal, then follows the learner's real second request and response. The new carrier cannot make the material disappear from the assessment.
