## What changed

`ComposedWorld` extends `SocionWorld` and its single transaction journal. An owned `CompositionRevision` retains an ordered set of named roles, exact child revisions and access contexts. Its constituents are owned memory revisions or already retained compositions. Learned capabilities remain in the actual lower memory that acquired them. A parent can contain another learned organization, and several roles can share the same child.

The elected law is a **versioned contextual directed acyclic graph proposal**. Existing historical references make the revision graph finite and acyclic. A later revision may include an earlier revision of the same named organization. Iterative traversal has no programmed depth ceiling. These properties describe the implementation; they do not prove recursive Cross coherence or unlimited useful development.

Paid fold stores direct addresses and an exact predecessor. Paid unfolding recovers exact constituent records and ordered role edges; shared records are visited once. Full structural unfolding retains every context. Contextual access follows the declared context and selects propositions by their original context and explicit time. Actor, object, context, revision and capability identities remain intact. Lower memory links and provenance stay recoverable addresses; they are not implicitly traversed as composition edges.

A completed contextual result can supply the existing R4 Theorize operation. Apply then executes the account, and Embody retains consequences and capacity. The new path pays its own fold/access costs plus the unchanged Model A routing, processing and physical-action costs. R6 exchange policies still run in this extended world.
