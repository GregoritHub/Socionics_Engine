# R10 sustained evaluation contract

The machine-readable declaration is `docs/acceptance_plan_R10.json`, written
before the first R10 workload run. All workload selection, scheduling, resource
replenishment and numerical performance thresholds are **implementation choices**.
Source anchors are the preserved roadmap R10 and foundation sections 1, 3, 5, 7
and 8. This evaluation does not alter the scientific status of earlier rules.

The main panel runs 36 worlds: three population sizes, two learned histories,
two resource regimes and three seeds. Each world retains its complete history
through three organization lifecycles. Seeds vary type assignments and supplied
ordering/opportunities; the simulated transition rules themselves are deterministic.
All 16 Model A types participate in each 16-actor world. This is a finite panel,
not a statistical estimate of behavior in an unspecified environment.

The experiment supplies one ownership object, training opportunities, requests
to formulate, communication opportunities, opportunities to act, one ownership
intervention per cycle, and opportunities to leave. Participants perform paid
operations to acquire meanings, select experienced terms, review and consent,
enact, dispute, revise and admit newcomers. The harness tracks protocol outputs;
it never supplies ready-made Terms or copies a peer's private memory. Scheduling
and replenishment are external experiment operations, not endogenous motivation
or a self-sustaining economy. The newcomer is an existing configured actor.

An ordinary successful run must preserve failure from the injected intervention,
fresh exact consent, changed disputed steps, and successful action after founder
departure. No-history, refusal and unaffordable work are successful *controls*
only if the world explicitly fails to form or complete the requested operation.
They are not successful organizations.

Timing separates command execution, offline evaluation, checkpoint encoding,
checkpoint replay and total experiment overhead. Participant energy/time debits
are simulation quantities, not CPU measurements. Profiles vary inactive ticks
and unrelated paid receipt history while holding the active selector fixed;
other profiles explicitly grow candidate or membership extent. Queue and index
counts are diagnostic snapshots outside timed active operations. Historical
jobs, receipts, packets and indexes are retained storage, not an executable queue.
The separate R6 controller's unconsumed notification queue is counted explicitly:
R10 drives the R9 protocol and does not schedule that controller to consume direct
inspection notifications. Zero unfinished organizational jobs is therefore not a
claim that every controller queue is empty or bounded.

The new independent offline oracle consumes configuration and journal records,
not runtime indexes or participant selection helpers. Its scope is resource
conservation, physical ownership outcomes, linked plan execution, local exact
consent and independently reconstructed practice summaries. It is not a second
implementation of all semantics or scientific laws. Earlier independent memory,
processing, composition and assessment references remain required tests.

The full release gate includes a fresh extracted source run. Passing establishes
this bounded rebuild's release acceptance; it does not establish unrestricted
composition, recursive Cross coherence, arbitrary institutional invention,
English conversation, generated Shell emergence/clearance, the Id/Identity
cycle, empirical psychological validity, or arbitrary-population efficiency.
