# Holonic Living Engine — R13

**Integrated content and developmental memory · 17 September 2026 · version 1.3.0**

**R12–R21 extension: 2/10 milestones complete; eight remain. Next: R14 — generated demands and participant-selected work.**

R13 integrates finite content crossing and personally learned contextual meaning into the same runnable engine as world actions, Fool’s Memory, Model A processing, material history, language and organization. The main runtime now checkpoints unfinished content and meaning work and continues with exact actions, resource charges and retained state.

## Run

Python 3.12 or later; standard library only. From this directory:

```bash
python -m hle
python tools/r13_evidence.py
python tools/r13_validate.py
python tools/validate_release.py
```

The default demo executes twelve held-out returns using retained rules, checks exact restoration, and shows meaning revision after a reversal in experience. Evidence and tests distinguish completed actions from merely selected plans.

Import the main runtime as:

```python
from hle.developmental import DevelopmentalWorld
from hle.content_records import ContentCommand, MeaningCommand
```

`hle.development_demo` supplies small reproducible examples. `hle.development_evaluation` supplies complete-journal continuation, two-actor history and independent resource-accounting witnesses.

## What is integrated

Content and meaning use versioned commands, the shared journal and actor-specific paid processing. Inference receipts remain evidence: executable retained rules must be acquired, written, bound and found through paid contextual recall. New contextual bindings can retrieve the same generic rule without making ordinary facts context-independent. Withdrawn/superseded capacity or a changed declared dependency cannot pass as current.

Personally meaningful expectations are learned from actual embodied consequences, not assigned by card label. Comparing samples, writing the revised association and publishing its binding are separately charged. Two continuing holons can use the same cue while learning different expectations and choosing different actual actions.

Eight bounded executable content roles cover all information elements. Payload aspect survives copying and changed sender activity. This is finite task semantics, not arbitrary-prose classification, universal psychology or completed individuation.
