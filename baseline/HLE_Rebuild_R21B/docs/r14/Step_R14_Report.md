# HLE R14 — generated demands and participant-selected work

17 September 2026 · Version 1.4.0

**R14 complete. Individuation and Shell-clearance extension: 3/10 milestones complete; seven remain. Next: R15 — generated compensation and material ownership.**

## What the release establishes

Persistent consequences now produce participant-discovered demands in the continuing main engine. The external scheduler supplies an actor an opportunity to process; it does not assign the subsequent loan request, lesson, cleaning task or return. The participant selects its work using permitted observations, personally retained motives, contextual memory and available resources.

The concrete world is a finite workshop. Seeded standing motives and predefined primitives remain explicit implementation choices, not spontaneously invented values or a general solution to autonomous motivation. Within this grammar, the generated demands, decisions, costs and further consequences are actual runtime work rather than controller labels.

## The completed feedback loop

A worker observes its owned raw workpiece and another participant's tool. It retains and recalls that information, recognizes a preparation need, and requests a loan. The holder considers the request using its own memory, needs, boundary and resources; it can lend or refuse. A granted loan includes the borrower's explicit accepted return condition.

Successful use changes the workpiece to ready. Under the declared physics it also leaves a dirty tool and makes the accepted return due. **The world records those effects, not a pair of new tasks.** After observation, paid memory and recall, the worker generates maintenance and return demands. It selects cleaning before return because the return operation needs a clean tool, then observes and remembers the consequences. The needs resolve only when permitted recalled facts establish their satisfied conditions.

The standard trace contains **188 events**, including the four consequential physical operations lend → use → clean → return. Other conditions produce different sequences: self-owned tools need no loan/return; wear-free use needs no cleaning; refusal produces no forced transfer. Two simultaneous needs are handled through their actual prerequisites, not a preassigned universal developmental sequence.

### Demand causality and controls

| Changed condition | Observed result |
| --- | --- |
| Remove wear | No maintenance demand; the accepted return still occurs. |
| Start with the actor's own tool rather than a loan | Maintenance occurs without a generated return commitment. |
| Disable the due-after-use trigger | No currently due return demand under that altered law; this is not certification of all future obligations. |
| Explicitly clean and return before discovery | Later recalled net state produces neither cancelled demand merely because transient use occurred. |
| Retain an effect but schedule only clock events | No direct insertion of a participant demand; discovery still requires actor observation/memory work. |
| Holder refuses | The requester does not seize the tool; known alternatives can remain exhausted/unresolved. |
| Remove the tool | Finite local search exhausts without inventing resources or declaring a universal impossibility. |
| Remove the native use technique, provide an experienced peer | An actual help request and supported lesson precede the learner's use. |
| Provide no supporting teacher experience | Refusal/unresolved need, not a fabricated lesson. |

The teaching case enables a **predefined finite use primitive** from communicated actual experience. It does not claim invention of an arbitrary new algorithm. Net-reversal interventions are labeled counterfactual fixtures and are absent from positive actor-only runs.

### Observation isolation

In a matched pair, an unseen ownership transfer was compared with a clock event at the same logical time. Simulator ownership differed, but the complete permitted local views, pure policy choices, paid actual decisions and resulting demand records were identical. A later permitted inspection changed what the actor could do: the newly informed owner used the tool, while the other case waited for a response.

Foreign memory, an unreceived request, wrong material/borrower consent and fabricated unsupported teaching are rejected. Losing or withdrawing a motive does not discharge an accepted physical obligation. Moving custody through an ordinary transfer does not cancel the separate loan relation.

### Quiet, uncertainty and resources

Satisfied or motive-free actors reach rest and remain unchanged under further clock-only events. Initialization and real evidence processing still have costs; absence of a problem is not manufactured perpetual activity. Silent peers, missing technique, refusal, stale contextual access, resource reserve and finite search exhaustion have distinct reasons and outcomes. None automatically receives a Shell or clearance label.

Budgets of zero, one, four and twenty units per resource produce explicitly censored work. A depleted partly completed run resumes after an explicit resource credit, and restored and uninterrupted schedulers select the same further work with identical complete journals. Need count, observed-state revision count, primitive-budget shortfall and repeated failed targets remain separate. The repetition measure is not a validated account of human boredom and does not drive activity merely because time passes.

## Integration, accounting and continuation

`AutonomousWorld` extends the R13 main runtime. No earlier behavioral runtime is replaced. The new records and operations use the existing event/memory/work address space, paid Model A processing and allowlisted checkpoint codec. Snapshots hold exact own-record references and proposition indices, not copied foreign histories or an unpublished policy answer. Decisions and generated demands are computed only after their declared processing cost is funded.

Every prefix of the standard trace—including its **six partial policy transactions**—restored and executed the remaining inputs to the identical full final checkpoint. Separate low-quantum tests cover partial physical, reception and memory work; fresh schedulers at five intermediate round boundaries independently choose the subsequent commands rather than receiving a saved solution sequence. Rehashed changes to a demand, action, payment or private snapshot fail replay.

The independent ledger fold reconciles every before/after wallet, credit and debit and checks the paid counters of physical and decision jobs. For the standard SLI case, **1,839 total quanta** comprise **1,599 policy-selection quanta**, **9 physical-operation quanta**, and the remaining memory/communication work. Policy work dominates this elected finite pricing model; these quanta are not host CPU time or a physiological energy estimate.

An independent bounded demand reconstruction agrees with the generated records using exact paid-recall snapshots, without invoking the live selection function or reading simulator Truth. A guarded-history test confirms that normal selected work does not iterate the whole journal after 500 inactive events. Current memory catalogues, current demand heads, archival storage and offline replay still have costs. R21 latency/storage scaling acceptance remains open.

## Failures found and repaired

The first inherited run exposed a genuine codec collision: registering the R12 `Opportunity` class overwrote the short wire name used by the different R5 assessment record. Historical checkpoint tests caught it. The codec now preserves the old tag and explicitly qualifies the later class, with exact-class encoder registration and tests for both round trips and same-named impersonation. **No inherited test was relaxed or changed.**

The same regression suite rejected new helper imports outside its original standard-library allowlist. Seeded declaration ordering now uses already permitted SHA-256 and counters use dictionaries; the original isolation test remains intact.

New resource tests exposed an attempt to start a policy turn while partly completed message reception held the shared processing reservation. The dispatcher now mechanically resumes the previously selected job before another paid decision. Unsupported message handling was also repaired to consume a neutral uninterpreted envelope once without fabricating a need. The first complete-prefix invocation was externally cut off; its incomplete log is retained and not counted as a pass. Subsequent full runs completed all 188 prefixes.

Of R13's **51 runtime modules, 48 remain byte-identical**. The three inherited changes are package version, default entrypoint and codec; five autonomy modules are added. All inherited test source files and the frozen R12 behavioral acceptance are unchanged. Original failed logs, source pins and repair explanations are included in `Test_Evolution_R14.json` and the evidence package.

## Completion boundary and next work

All three frozen R14 gates have executed witnesses: persistent consequences generate different discovered demands; observation-matched hidden Truth cannot steer a decision; and rest/refusal/resource/unresolved outcomes remain honest. The release therefore completes **R14**, not the later developmental mechanism.

The next milestone is **R15 — generated compensation and material ownership**. It must produce a genuinely self-maintaining pattern from processing and history, with real recurring costs and locally selected carrier consequences—not relabel one of R14's legitimate waits or failures as a Shell. The joint five-sign detector, conversion, full individuation, clearance and recursive/shared closure remain R16–R20.

Large historical R10/R11 population studies and the full earlier memory-probe population panels were not newly rerun. Their bundled results retain historical status; the fidelity suites listed here were rerun. The frozen **480-case R21 evaluation remains unexecuted**. No unrestricted-complexity or human empirical-validity claim is made.
