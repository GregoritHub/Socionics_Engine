# Shell Study 05 — optional experimental engine

This is a research module. It leaves the working engine, sealed baseline, release state and default behavior unchanged. The launcher exports pinned source and applies the experimental patch in a new directory outside your checkout.

## What it compares

- Load: total request size versus unfamiliar targets after accessible exact local corrections.
- Reownership: historical returns, fresh returns after observed pattern-wide recurrence, or freshness within the retained load claim.
- Formation and subsequent approval-supported performance have separate evidence; no new reinforcement-learning law is implemented.

Six combinations were tested in IEE and SLI. The original Study 05 audit passed 98 native checkpoint outcomes, with 14 byte-identical baseline comparisons. See [report.html](report.html), [audit.json](audit.json), and [evidence.json](evidence.json). These counts describe the original study, not a new repository-wide regression.

## Run

Requires Python 3.12+, Git, and `patch`. Use a full Git clone containing baseline commit `ab674a36e9234dcbf46634367bfc2b42b8b3cd18`.

Download **Shell_Native_Evidence_05.zip** from ChatGPT Library. Its immutable identifiers and SHA-256 are in `evidence.json`. The archive contains raw runs, prior failure records and the four input checkpoints. No credentials or network access are used by the launcher.

From the repository root:

```bash
python3 research/shells/study05/launch.py \
  --evidence /absolute/path/Shell_Native_Evidence_05.zip \
  --output /absolute/path/new-shell-study05-run
```

Add `--smoke` for the seven-case IEE pattern-freshness packaging check. The full command runs all 98 outcomes and the independent raw-checkpoint auditor. Output must be a new directory outside the repository. Failed attempts are retained. The selected rule is recorded as a replayable configuration command; historical actions retain their original behavior.

## Validated boundaries

One generated pattern in its exact context, distinct targets, native capacity two. Multiple matching patterns, duplicate targets, stale capacity revisions, delayed observation permutations and adversarial configuration are not validated. Scope freshness was tested against out-of-scope overload, not a discriminating within-capacity recurrence. Difficulty weights, coupling and schedule validity are not integrated. The inherited aggregate assessment is not a fresh-recovery certificate.

The original engine and research paper meanings remain authoritative; this module introduces selectable hypotheses, not replacement defaults. No theoretical register is closed. This explicit research addition does not restart the completed Final Build or authorize Phase 7.
